# Estudios bíblicos

Estudios para acompañar la lectura de la Biblia en pareja: unos 20 versículos por día, media hora de lectura y estudio.

## Génesis (en preparación)

El estudio se arma solo con el material de nuestra biblioteca, sin inventar nada: cada nota lleva su fuente y su página.

- **Comentarios de Génesis:** Meredith G. Kline (*Nuevo Comentario Bíblico*), *Comentario Bíblico Beacon*,
  *Comentario Bíblico Mundo Hispano*, Alfred Edersheim, *Biblia de Estudio MacArthur* y el *Diccionario Bíblico Mundo Hispano*.
- **Libros de referencia:** solo de autores protestantes confiables (ver `genesis/trabajo/clasificacion/`).
- **Texto bíblico:** Reina-Valera 1960.

`genesis/trabajo/` guarda el trabajo intermedio: notas extraídas de cada comentario, la clasificación de autores,
el plan de lectura y los scripts.
